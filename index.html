Features

Everything you need to stay on top of recurring payments

A focused set of tools built around one question: what am I paying for, and when?

All in one place

Streaming, music, gym, insurance, internet: every subscription in a single list.

Add, edit, delete

Set name, amount, category, billing cycle, due day, payment method, color and notes.

Monthly & yearly costs

See your estimated monthly spend and what's due in the next 7 days at a glance.

Upcoming renewals

Your next payment is always highlighted, with how many days are left until it's due.

Renewal reminders

System notifications the day before each charge, toggled on or off per subscription.

Spending insights

Breakdown by category, by payment method and by billing cycle: monthly vs. yearly.

Search & filter

Find any subscription instantly, filter by category and sort by price, name or due date.

Quick templates

Load popular services like Netflix, Spotify or Xbox Game Pass in one tap to get started fast.

Your data, your phone

Private by design

Gestio keeps your subscriptions in a local database on your own device. No ads, no analytics, no tracking.

  • Stored locallyEverything lives in an on-device Room database.
  • No account requiredOpen the app and start adding subscriptions right away.
  • Reminders that work offlineNotifications are scheduled on the device with Android alarms.
  • Fully open sourceRead every line of code on GitHub.

Under the hood

Modern Android, 100% Kotlin

Built with the current recommended Android stack, with a simple layered architecture that's easy to read and extend.

KotlinThe whole codebase
Jetpack ComposeDeclarative UI
Material 3Components & theming
RoomLocal SQLite persistence
Coroutines & FlowAsync, reactive data
AlarmManagerScheduled reminders

Architecture: Room DAO → Repository → ViewModel → Compose UI, with a BroadcastReceiver for notifications.

Get the code 
# Clone the repository
$ git clone https://github.com/minithiago/Gestio_App.git
$ cd Gestio_App

# Build and install on a connected device
$ ./gradlew installDebug
  1. Or open the project in Android Studio and let Gradle sync.
  2. Run it on a device or emulator with Android 7.0 (API 24) or newer.
  3. Targets Android 16 (API 36).
